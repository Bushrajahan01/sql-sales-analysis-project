# SQL Sales Analysis Project

## Project Overview

This project analyzes sales transaction data using MySQL and Microsoft Excel to identify revenue trends, top-performing products, customer purchasing behavior, and city-wise sales performance.

The objective is to transform raw sales data into meaningful business insights and support data-driven decision-making.

---

## Tools Used

- MySQL
- SQL
- Microsoft Excel

---

## Dataset Information

The dataset contains the following fields:

- Order ID
- Order Date
- Product
- Category
- Quantity
- Price
- Customer
- City

---

## Analysis Performed

- Total Revenue Analysis
- Product Revenue Analysis
- Customer Spending Analysis
- City-wise Revenue Analysis
- Monthly Revenue Trend Analysis
- Category Revenue Analysis

---

## Key Findings

- Total Revenue: ₹167,250
- Laptop generated the highest revenue
- Pen was the highest-selling product by quantity
- Ravi was the highest-spending customer
- Mumbai generated the highest revenue
- February recorded higher revenue than January
- Electronics was the top-performing category
